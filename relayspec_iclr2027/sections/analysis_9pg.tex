We analyze how the learned maps change the hidden-state context passed to the frozen drafter. Appendix~\ref{app:analysis-probes} reports every measurement, control and negative result.

\subsection{What changes when the interface already works?}
\label{sec:analysis-lora}
For a LoRA-fine-tuned target, identity maps recover the native interface. Write $z_0=\sum_i F_i h_i$ for this context and $\delta=\sum_i F_i(W_i-I)h_i$ for the correction. Decoding with $z_0$ plus only the parallel component of $\delta$ returns acceptance to the native level, 4.466 against 4.472 on GSM8K, while the perpendicular component alone recovers nearly all of the full map's acceptance, 5.924 against 5.988 (Appendix~\ref{app:lora-direction}). The useful change is directional, consistent with RMSNorm suppressing common rescaling. The maps do not reverse the LoRA shift: correction cosines are $-0.0429$ and $0.1248$ against shuffled controls of $-0.0413$ and $0.1052$ (Appendix~\ref{app:lora-geometry}), so they redirect an already usable context rather than recovering the pre-LoRA one.

\subsection{Why does reconstruction help across model sizes?}
\label{sec:analysis-transfer}
For a Qwen3-8B target with a Qwen3-4B drafter, MSE recovers the interface the frozen drafter was built for: context error 0.136 against 0.940 for AUF and 0.900 for decay CE (Appendix~\ref{app:transfer-geometry}). This transfers to prediction, where MSE gives the lowest cross-entropy and longest correct prefix on MATH, Code and Chat, and averaging a token-trained map with its MSE counterpart improves live throughput without retraining (Appendices~\ref{app:heldout-diagnostics} and~\ref{app:midpoint-full}). Initialization does not explain this (Appendix~\ref{app:identity-init}).
